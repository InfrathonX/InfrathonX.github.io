Codec comparison

We compare the codec developed by Claude Opus 5.5 during a 24-hour run with the human Quant-VideoGen codec. The evaluation uses HY-WorldPlay on WorldScore and LongCat-Video on MovieGen, with 200 samples per dataset.

Evaluation setup

Both codecs and the uncompressed BF16 reference use the same inputs and generation settings.

PSNR, SSIM, and LPIPS compare the first segment generated with compressed KV against the BF16 reference.

Human versus Claude

Entries report Human → Claude. Higher compression, PSNR, and SSIM are better; lower LPIPS is better.

What the agent discovers

The human codec quantizes the residuals left after clustering the cache one value at a time. Claude instead transforms those residuals using principal component analysis and applies entropy coding after quantization.

Claude’s codec improves compression and video quality. Mean PSNR increases by approximately 5.2 dB on WorldScore and 3.3 dB on MovieGen.

Improvements across submissions

From submission 16 to 22, compression rises from approximately 16.6× to 18.8× on both displayed samples while mushroom textures and facial details become clearer.

Building new discovery tasks

Infrathon-build helps researchers turn their own infrastructure problems into tasks. Infrathon then supplies an execution and feedback loop for comparing agent solutions with existing implementations and iterating from test feedback.
