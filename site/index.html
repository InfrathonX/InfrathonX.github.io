Scoring and token definitions

Rank the six models by each task’s best valid within-budget score, then average 100 × (6 − rank) / 5 equally across tasks. Exact ties share average rank; a run without a valid scored submission receives zero. The 95% task-bootstrap confidence intervals use 10,000 resamples for the full suite and 3,000 for filtered groups.

Visible tokens use o200k_base for agent text and tool-call content, excluding tool responses, repeated code-diff displays, and hidden reasoning. Full-suite totals aggregate all 25 tasks. First-score time is the median across scored runs in the selected tasks.
